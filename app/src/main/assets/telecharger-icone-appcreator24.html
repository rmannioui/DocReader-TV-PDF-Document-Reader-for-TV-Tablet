Icône Spéciale AppCreator24

Voici l'icône officielle prête au format 512 × 512 px (PNG) exigé par AppCreator24.

⬇️ TÉLÉCHARGER L'ICÔNE (512x512 PNG)

📋 Comment l'utiliser dans AppCreator24 :

  1. Téléchargez l'icône ci-dessus en cliquant sur le bouton rouge.
  2. Rendez-vous sur AppCreator24.com et connectez-vous.
  3. Dans votre application, allez dans le menu General info ➔ Name and icon.
  4. À la ligne App icon, cliquez sur « Choose file » (Parcourir) et sélectionnez app_icon_appcreator24.png.
  5. Dans Sections ➔ Créez une section de type Web et collez l'URL de votre site :
    https://USERNAME.github.io/REPOSITORY/
  6. Cliquez sur Save puis générez votre APK !
